# Exercise Library

> Purpose: pick specific exercises (by movement pattern, equipment, skill, fatigue cost, role) and substitute them when equipment, skill, injury or fatigue demand it.
> Use when: filling the exercise slots of a session template, substituting an exercise, choosing isolation work for a priority muscle, or building power/conditioning/warm-up blocks.
> Depends on: [variables](03-variables.md) (sets, reps, RIR, rest), [session design](05-session-design.md) (order, slots, supersets), [splits](06-splits.md) (pattern allocation per day), [populations](11-populations.md) (injury/age constraints), [conditioning](09-conditioning.md)

## Key rules (TL;DR)

1. Choose **pattern first**, then filter: equipment → skill ≤ trainee level → fatigue/axial fit for the session slot → injury constraints. Ratings in the tables are coaching-consensus defaults `Practitioner`, not measurements [14].
2. **Roles:** Main = heaviest, first, 3–5 sets, 3–8 reps (strength 1–6). Secondary = 2–4 sets, 6–12 reps. Accessory = 2–4 sets, 8–15 reps (isolation 10–20; calves 8–20). Core 2–3 sets. Per-exercise sets stay within 2–4 (up to 5 for peaking/technique); see [variables](03-variables.md).
3. **Tie-breaker = lengthened bias.** When two options are otherwise equal, take the one that loads the muscle at long length (overhead triceps extension, seated leg curl, standing calf raise, incline curl, RDL, deep squat) [1][2][9] `Moderate`. A lengthened-*partial* advantage is **not** established `Contested` [5][6].
4. **One exercise rarely covers a whole muscle.** Quads: squat/leg press (vasti) + knee extension (rectus femoris) [4]. Hamstrings: hinge + seated leg curl [2]. Triceps: overhead extension first [1]. Biceps: incline + preacher/hammer [8]. Calves: standing first [9]. Each is a single small trial `Moderate`.
5. **Glutes:** hip thrust ≈ back squat for glute growth (9 wk, untrained, MRI); squat grew more quads/adductors [3] `Moderate`. EMG amplitude did not predict growth [3][13] — never select by EMG alone.
6. **Beginner pool = Skill B, Axial L–M only** (list below). Defer conventional deadlift, front squat, standing OHP, Olympic lifts, Nordics, pistols until technique is established.
7. **Fatigue budget:** when recovery is tight (many hard sessions, deficit, poor sleep, hybrid training) swap High-fatigue/High-axial lifts for Low–Medium options (leg press for squat, chest-supported row for bent-over row, machine press, hip thrust for hinge) [14] `Practitioner`.
8. **Stability:** keep main lifts constant 4–8 weeks; rotate accessories at block ends. Systematic variation is fine, frequent random rotation is not [7] `Moderate` (thin).
9. **Fractional counting:** primary muscle = 1 set, listed secondary = 0.5 set; skip a secondary role if involvement is minor. Do not double count.
10. **Core minimum per week:** ≥1 anti-extension + ≥1 anti-rotation/anti-lateral-flexion exercise; carries count as anti-lateral-flexion. Flexion optional.
11. **Power/plyo goes early and fresh:** after warm-up, before heavy lifts, ≤40–80 contacts/session, full rest (1–3 min); skip when sore or very fatigued [12].
12. **Pain:** substitute within the pattern (change ROM, load path, grip, stance or machine), keep training unaffected regions, refer red flags. No diagnosis or treatment advice.

## How to pick exercises

### Column definitions (consistent values — filter on these)

| Column | Values | Meaning |
|---|---|---|
| Skill | B / I / A | B = learnable in 1–3 sessions, low risk. I = needs cueing/practice weeks. A = technical (Olympic derivatives, loaded deep unilaterals, Nordics, pistols). Ranges like `B–I` = depends on variant/load. |
| Fatigue | L / M / H | Systemic fatigue cost. L = local only (isolation, machines). M = multi-joint, moderate or supported. H = heavy axial/whole-body (conventional deadlift, heavy back squat, Olympic lifts). |
| Axial load | L / M / H | Spinal compression. L = supported/seated/prone/hanging. H = bar on back or heavy deadlift. |
| Role | Main / Secondary / Accessory | Slot in a session. Main first (heaviest, 3–5 sets), Secondary second compound, Accessory single-joint or machine. |
| Primary / Secondary | muscles | Primary counts 1 set, Secondary 0.5 set (fractional counting). Lists typical, not exhaustive. |
| Reps | range | Typical working range; heavy compounds can go to 3–5. `/side` = per limb. |
| Impact (conditioning table) | Low / Medium / High | Joint-impact cost. |

### Beginner / novice safe pool (Skill B, Axial L–M)

Goblet squat, leg press, DB RDL (hip hinge), hip thrust, push-up, DB bench, machine chest press, seated cable row, lat pulldown, DB shoulder press, cable pushdown, DB curl, plank, dead bug, farmer carry.

### Main / secondary / accessory quick list

- **Main candidates:** back/front/safety-bar squat, hack squat, leg press (hypertrophy), conventional/trap-bar deadlift, RDL, hip thrust, barbell/DB bench, incline press, OHP/seated DB press, barbell/chest-supported row, pull-up/chin-up/pulldown.
- **Secondary:** split squat/Bulgarian, lunges, RDL (as secondary), DB press variants, cable row, close-grip bench, dips.
- **Accessory:** all isolation tables, core, carries.
- **Good superset pairs:** biceps↔triceps; chest press↔row; lateral raise↔rear-delt fly; leg extension↔leg curl; calf raise↔core; Pallof↔push-up; hip thrust↔pull-up.
- **Poor superset pairs:** squat↔deadlift; heavy row↔heavy RDL (back fatigue); two grip-heavy pulls.

| Vertical pull | Pull-up/chin-up, lat pulldown | Band-assisted pull-up, band/DB pullover, band-resisted pulldown | Pull-ups/chin-ups (assisted/negatives), scapular pulls; no bar → towel/door row emphasis | Neutral-grip pulldown, assisted pull-up, straight-arm pulldown (shoulder/elbow irritation) |
| Carry / trunk bracing | Farmer, suitcase carry, Pallof press | KB/DB carries, band Pallof | Plank variations, dead bug, bird dog, side plank, bear crawl | Dead bug/bird dog, Pallof press (low-back sensitivity) |

Overload without heavy load (bodyweight/home), in order of ease: (1) get closer to failure (≈1–3 RIR) with higher reps (15–30+); (2) slower eccentrics (3–4 s) and pauses; (3) harder leverage (incline → decline, two-leg → single-leg); (4) more ROM (deficit, elevated feet); (5) add load (backpack, bands, water jugs); (6) shorter rest / density techniques; (7) unilateral variants. `Practitioner` [17].

## Decision rules

1. IF building a session THEN pick pattern first, then filter by equipment, skill ≤ trainee level, fatigue/axial fit for the slot, injury constraints.
2. IF trainee is a beginner THEN restrict to Skill B, prefer machines and goblet/DB variants; avoid conventional deadlift, front squat and standing OHP as main lifts until technique is established.
3. IF session ≤45 min THEN choose main lifts with high muscle coverage (leg press/hack/squat, bench/DB press, row/pulldown, RDL) and superset non-competing pairs (quad + horizontal pull, biceps + triceps, calves + core) — see [session design](05-session-design.md).
4. IF fatigue budget is tight (multiple hard sessions, deficit, poor recovery, hybrid week) THEN prefer L/M fatigue + L axial options [14].
5. IF quad hypertrophy is a goal THEN include one squat/leg-press pattern AND one knee-extension exercise [4].
6. IF hamstring hypertrophy is a goal THEN include one hinge (RDL) AND one knee-flexion exercise; prefer seated leg curl [2].
7. IF glute hypertrophy is a goal THEN pair squat/lunge/hinge with hip thrust (or bridge) [3].
8. IF triceps hypertrophy is a goal THEN lead with overhead extension, then pushdown/dip for extra volume [1].
9. IF biceps hypertrophy is a goal THEN use incline curl + (preacher or hammer) curl; vary across blocks [8].
10. IF calves are a goal THEN standing calf raise (full stretch) first, seated optional [9].
11. IF no equipment THEN push-up family, pike push-up, inverted/towel row, split squat/step-up/Bulgarian on furniture, single-leg RDL with a bag, glute bridge, slider hamstring curl, plank family, bands if available.
12. IF dumbbells only THEN DB bench/floor press, DB OHP, one-arm row, goblet/Bulgarian/DB RDL, DB hip thrust, lateral raise, curl, overhead extension, farmer carries.
13. IF a movement causes joint pain (shoulder with OHP, knee with deep lunge) THEN swap to a pattern-equivalent with a better joint angle (landmine press, reverse lunge, box squat, leg press); conservative rule: pain ≤3/10 during and settled by next day, otherwise regress one level [17] `Practitioner`; recommend a clinician for persistent pain; do not diagnose.
14. IF plyometrics/power are scheduled THEN place after warm-up and before heavy lifts, ≤40–80 contacts, full rest; skip when sore/fatigued [12].
15. IF Olympic lifts requested by a non-experienced trainee THEN substitute KB swing, jump squat or med-ball throw; Olympic lifts need coaching, reps ≤3–5 [15].
16. IF impact is a concern (joint issues, high bodyweight, deconditioned) THEN choose low-impact conditioning (bike, rower, sled, ski erg, carries) over burpees/running/jump rope.
17. IF plan ≥4 weeks THEN keep main lifts constant, rotate accessories at block end [7].
18. IF supersetting THEN pair antagonists or non-competing upper/lower; never two heavy axial lifts or two grip-heavy pulls.
19. IF core is scheduled THEN ≥1 anti-extension and ≥1 anti-rotation/lateral exercise per week.
20. IF fractional counting THEN primary = 1, listed secondary = 0.5; ignore minor involvement (e.g. chest in OHP).

## Common mistakes

- Treating fatigue/skill ratings as measured facts.
- Choosing by EMG alone [3].
- Only squats for quads (ignores rectus femoris) [4]; only pushdowns for triceps (ignores long head) [1]; seated calf raise as the only calf work [9].
- Rotating all exercises weekly with no progressive overload on any lift [7].
- Heavy axial loading on consecutive days (squat + deadlift + OHP + heavy row).
- Skipping carries and anti-rotation core entirely.
- Prescribing Olympic lifts or depth jumps to beginners without a coach.
- Using burpees/sprints as finishers for people with joint concerns.
- Double counting secondary muscles in volume totals.

## Evidence notes

- **Ratings are author-assigned consensus** (skill, fatigue, axial, role, reps); no peer-reviewed rating system exists `Practitioner`. SFR is criticized as unevidenced [14].
- **Selection trials are single, small, 8–12 wk, mostly untrained** [1][2][3][4][8][9]. Trained-population and long-term effects are unstudied. Several were read via secondary summaries; percentages vary across reports — quote them as approximate.
- **Lengthened-position training** `Contested`: partial-ROM CI crosses zero [5][6].
- **Seated hip-flexed leg extension** biasing rectus femoris: unverified preprint-level claim; ideal hip angle unknown.
- **Plyo dose** differs by meta-analysis (>50 jumps/session vs <900 total) [12].
- **Core training** direct benefits: limited evidence; anti-rotation EMG small [16].
- Not covered by evidence: Olympic-lift injury rates; long-term trained-population comparisons.
- Pain thresholds are rehab-research conventions, not validated for general lifting or low-back pain [17].
