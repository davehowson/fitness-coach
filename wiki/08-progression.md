# Progression & Periodization

> Purpose: decide how a lifter's loads, reps and sets change from session to session and across weeks, build a mesocycle with a deload, and diagnose plateaus.
> Use when: writing the progression/deload rule for any resistance plan, choosing a progression model for a given experience level, building a 4–8 week block, or responding to a stall.
> Depends on: [principles](01-principles.md), [variables](03-variables.md) (sets, RIR, rest, reps), [weekly planning](07-weekly-planning.md), [program templates](13-program-templates.md)

## Key rules (TL;DR)

1. **Having a progression rule matters more than which periodization label you use.** Every plan must state: (a) the per-lift progression rule, (b) the failure/reset rule, (c) the mesocycle length, (d) the deload rule. (Moderate; ACSM 2026 [1], Moesgaard 2022 [2])
2. **Classify experience by how fast progress happens, not by years.** Beginner = progress session to session; intermediate = week to week; advanced = month to month or block to block. [3][4] (Practitioner)
3. **Default model = double progression** (rep range + target RIR; add load when the top of the range is hit at target RIR on all sets). Use it for hypertrophy work, accessories, and any non-novice. (Moderate)
4. **Beginners on main barbell lifts: linear progression per session.** +2.5 kg / 5 lb upper, +5 kg / 10 lb lower, with a defined reset on failure. Beginners need no formal periodization and rarely a deload.
5. **Mesocycle default = 5 working weeks + 1 deload.** Allowed 4–8 weeks. Volume ramps ~+1 set/muscle/week; RIR falls 3 → 1. (Practitioner)
6. **Deload default = ~1 week, cut sets 30–50%, keep load mostly, keep RIR ≥3.** Trigger: every 4–8 weeks of hard training, or earlier on fatigue signals. (Practitioner; Coleman 2024 RCT n=39: a full rest week did not change hypertrophy; continuous training gave slightly better lower-body strength [5])
7. **Periodized beats non-periodized for 1RM strength only modestly** (Moesgaard 2022 ES 0.31, CI 0.04–0.57); **no difference for hypertrophy** (ES 0.13, n.s.). Undulating beats linear for 1RM only in trained lifters. [2] (Moderate)
8. **Plateau = no progress on a priority lift for 3–4+ weeks** (vs the recent 6–8 week best) with sleep/nutrition consistent. Check fatigue, volume and technique before changing the program. (Practitioner)
9. **Keep main lifts constant for a whole mesocycle; rotate ~30–50% of accessories between mesocycles**, same movement pattern and muscle target. (Moderate-weak)
10. **Log load, reps, sets, RIR/RPE, date, bodyweight, notes every session; judge trends over ≥3–4 weeks**, not single sessions. 1RM test-retest noise is 3–5%. [4]
11. **RIR self-estimates run ~1 rep too low on average** (lifters have more left than they think). Trust late-set and ≤12-rep estimates more. [6] (Moderate)

## Progression models

A *progression model* is the rule that changes one lift from session to session. A *periodization model* (later section) is the planned variation of volume/intensity across weeks. Levers of overload: load, reps, sets, lower RIR, density, technique/ROM quality. Load and reps are primary; load-progression and rep-progression gave near-identical hypertrophy in an 8-week RCT of 43 trained participants (Plotkin 2022) [7] (Moderate, single RCT). So effort and volume matter more than which lever you pull.

### Model summary

| Model | Rule | Use for |
|---|---|---|
| Linear progression (LP) | Add fixed load each session (or each week) while all prescribed reps are completed | Beginners, main lifts |
| Double progression (**default**) | Work in a rep range at target RIR; when all sets reach the top, add the smallest load jump and drop to the bottom of the range | Hypertrophy, accessories, all non-novices |
| Rep-range progression | Same idea, looser: add reps within range, change load by feel | Hypertrophy, small muscles |
| Set progression | Add sets across weeks at fixed load (the mesocycle volume ramp) | Hypertrophy mesocycles |
| RPE/RIR autoregulation | Pick the load each day that hits the target RPE/RIR | Intermediate+, variable readiness |
| Percentage-based | Load = % of 1RM or training max (TM) per a weekly plan | Intermediate strength |
| AMRAP / TM-based | Final set "as many reps as possible" (usually leaving reps in reserve); result sets the next TM | Intermediate strength |
| Top set + back-offs | One heavy top set at target RPE, then reduced-load sets (−5–10%) | Intermediate/advanced strength |

Autoregulated (RPE/RIR, velocity) and percentage-based loading gave similar 1RM strength in meta-analysis (Hickmott 2022; few studies) [8] (Moderate). Velocity-loss thresholds ≤25% gave larger 1RM gains but smaller muscle-size gains than >25% [8][9]; do not generalize velocity data to RPE.

### Linear progression (beginner)

| Item | Rule |
|---|---|
| Increment | Upper +2.5 kg (5 lb); lower +5 kg (10 lb) per session |
| Sets × reps | Main lifts 3×5 (deadlift 1×5 — high fatigue cost); stay 2–3 RIR, no failure sets |
| Failure (missed reps at the prescribed load) | Repeat the load next session |
| Reset | Repeat failures → drop the load and rebuild with smaller steps. Generic rule: after 2–3 failed sessions at the same load, drop ~10% (range 5–15%) |
| Exit | Move to double progression or weekly/cycle progression when resets happen on 2–3 lifts |

Reference-program resets (use the exact version when naming a program; do not mix rules between programs):

| Program | Reset rule |
|---|---|
| Starting Strength | **Second consecutive failure** at the same load → reset 5% and make the next squat day light (80% × 2×5); if already doing that, switch to 5×3. Layoff: 1 week = repeat last workout; longer = 5% (<40 y) or 10% (>40 y); 3–4 weeks = 10%. Press and bench **alternate every session**. [10][11] |
| StrongLifts 5x5 | Repeat the weight; if it still fails after three attempts → deload ~10%. +5 lb (2.5 lb/side) when all sets are completed. [12] |
| Reddit PPL (Metallicadpa) | Fail a session 3 times in a row → deload 10%. Increments **+5 lb upper and squat, +10 lb deadlift** per session. Accessories: double progression (add weight at 3×12). [13] |
| GZCLP | Fail → next stage (T1 5×3+ → 6×2+ → 10×1+; T2 3×10 → 3×8 → 3×6). After the last T1 stage: test a new 5RM and restart at 85%. Increments +5 lb bench/OHP, +10 lb squat/deadlift. [14] |

Greyskull LP (original increments) is **unverified**; only secondary and Phrak-variant descriptions exist (2×5 + final 5+ set; +2.5 lb upper / +5 lb lower). Do not present it as official.

### Double progression recipe (default)

| Item | Value |
|---|---|
| Rep range | Compounds 5–8 (strength-leaning) or 6–10; accessories 8–15; isolation 10–20 |
| Target RIR | 2 (default; see [variables](03-variables.md)). Heavy barbell compounds and beginners: 3. Final isolation set may go to 0–1 |
| Add-load trigger | All working sets reach the top of the range at target RIR (autoregulated variant: set 1 only) |
| Load jump | Smallest available: ~2–5% lower body, ~1–3% upper. Re-selecting load: ~4% of load per rep outside the range |
| After a load add | Expect to land near the bottom of the range; rebuild reps |
| Reset | Bottom of range unreachable at target RIR for 2 consecutive sessions → drop load 5–10% |
| Fixed jump too big (e.g. dumbbells) | Progress reps within range, then add a set, then increase load |

Fixed-weight jumps are relative: +5 lb is 3.7% on a 135 lb squat but 1.2% on a 405 lb squat [4]. ACSM 2009 rule: when you exceed the target reps by 1–2 at the current load, raise load 2–10% [15] (dated; use as an upper bound, smaller for small muscle groups).

Worked example: 3×8–12 @ 2 RIR, lateral raise. Week 1: 8/8/8 at 10 kg. Add a rep per session or week: 10/9/9 → 12/12/12. At 12/12/12 at 2 RIR → next session 12 kg and expect ~8/8/8.

### Percentage / TM-based and AMRAP schemes

**5/3/1 (Wendler)** — TM = 90% of estimated 1RM. Wave of % of TM [16][17]:

| Week | Sets × reps (last set AMRAP "+") | After main sets |
|---|---|---|
| 1 | 65% ×5, 75% ×5, 85% ×5+ | FSL 5×5 at 65% (optional) |
| 2 | 70% ×3, 80% ×3, 90% ×3+ | FSL 5×5 at 70% |
| 3 | 75% ×5, 85% ×3, 95% ×1+ | FSL 5×5 at 75% |
| 4 (deload, when the 4-week form is used) | 40% / 50% / 60% ×5 | — |

- TM increase per cycle: **+5 lb (≈2.5 kg) upper, +10 lb (≈5 kg) lower**, regardless of AMRAP performance. Too-fast TM increases are the usual error.
- 5/3/1 BBB: main sets + 5×10 at 50–60% TM (start ~30% TM for new lower-body BBB) [18].
- Stall rule (lower TM by three increments = 15 lb upper / 30 lb lower) and the TM-test week (~every 10th week) are **r/Fitness-wiki additions, not original 5/3/1**. Label them so. [16]
- The week 2/3 percentages beyond what the wiki lists, and the 4th-week 40/50/60 deload, come from the standard published template via secondary summaries [17] (Practitioner).
- AMRAP sets should leave reps in reserve; stop when bar speed slows.

**nSuns 5/3/1 LP** — TM starts at 90% of 1RM. Original poster's weekly TM change from the AMRAP set: **0–1 reps → no change; 2–3 → +5 lb; 4–5 → +5–10 lb; >5 → +10–15 lb.** The "+5/+10/+15 per session" scheme is a Liftosaur app implementation, not the original. The 9-set tables are **unverified**. Start with the 4-day version. [19]

**Texas Method** (weekly intermediate): Volume day squat 5×5; Light day squat 2×5 at 80% of Volume day; Intensity day new 5RM (squat), 3RM (bench/press). Stall fixes: cut volume-day sets (5×5 → 3×5), lower volume-day weight 5–10%, change the Friday rep scheme. The "volume day = 90% of Friday 5RM" figure is **unverified**. [20]

**Top set + back-offs**: top set at RPE 8 (2 RIR) then 1–3 back-off sets at −5–10% (practitioner convention). Increase next week's top-set load when the top set is completed at ≤ target RPE. (Practitioner)

### Choosing a model by experience level

| Level (progress signature) | Model | Lower compound | Upper compound | Isolation / accessory | Increase cadence |
|---|---|---|---|---|---|
| Beginner (progress each session; roughly first 6–12 months) | Linear progression | +5 kg (10 lb) per session | +2.5 kg (5 lb) per session | Double progression: +1 rep/set to the top of range, then +1–2.5 kg | Every session; weekly if sessions stall |
| Intermediate (progress weekly–monthly) | Double progression / RIR; strength: 5/3/1-style wave or top set + back-offs | +2.5–5 kg when top of range hit; or TM +5 kg (10 lb) per cycle | +1.25–2.5 kg; or TM +2.5 kg (5 lb) per cycle | +1 rep/week, load up at top of range | Weekly–monthly; per 3–4-week cycle for TM schemes |
| Advanced (progress per block) | Block, or top set + back-off with RPE; autoregulated top sets | +1–2.5% per block | +1–2.5% per block | +1–2 reps/month in the 10–20 range | Per block (4–12 weeks) |

Typical rates: untrained +15–30% 1RM in 12 weeks; well-trained ~+2–6%/year [4]. Before changing anything, confirm progress against the expected rate for the level. Labels are crude (Barbell Medicine): progress should follow demonstrated performance, not a preset calendar. [4]

IF the user's classification is unclear THEN start at the lower level for the main lift and let the rate of progress promote them.

## Periodization models

Microcycle ≈ 1 week. Mesocycle ≈ 3–8 weeks of consistent focus. Macrocycle ≈ months to a year (several mesocycles + peak/transition).

| Model | Structure | Evidence / when to use |
|---|---|---|
| Linear (traditional) | Volume falls, intensity rises across phases (e.g. 12 → 8 → 5 → 3 reps over weeks/months) | Fine for novices; for hypertrophy LP ≈ undulating (Moesgaard ES 0.05, n.s.) [2] |
| Reverse linear | Intensity falls, volume rises across phases | Little evidence; endurance/hypertrophy-late emphasis (Practitioner) |
| Daily undulating (DUP) | Rep/intensity target changes each session (e.g. Mon 5s, Wed 10s, Fri 3s) | Undulating > linear for **1RM only in trained lifters** (ES 0.61, CI 0.00–1.22); untrained ES 0.06 [2]. Good fatigue management when a lift is trained ≥2×/wk |
| Weekly undulating (WUP) | Target changes week to week | Comparable; use when sessions per lift per week = 1 |
| Block | Sequential 2–6-week blocks: accumulation (volume) → transmutation/intensification → realization/peak | Peaking for a dated test/meet; evidence conflicting (Bartolomei 2014: block better for upper-body strength/power in trained men over 15 weeks, not lower body) [21] (Contested) |
| Conjugate (Westside) | Concurrent max-effort (1–3RM, rotated every ~1–3 weeks), dynamic-effort (~50–70%, 8–12 sets of 2–3 fast reps, ~60 s rest), repetition-effort | **No controlled trials.** Coach-derived (Practitioner). Offer only to advanced lifters who want variety |

Pooled evidence (Moderate):
- Periodized vs non-periodized, volume-equated, 35 studies: 1RM ES **0.31** (95% CI 0.04–0.57); hypertrophy ES **0.13** (−0.10–0.36, n.s.). [2]
- Linear vs undulating hypertrophy ES **0.05** (−0.20–0.29): no difference. [2]
- Earlier Williams 2017 meta-analysis (18 studies, 81 effects): ES 0.43 (0.27–0.58) for periodized 1RM; methods disputed in a published comment; periodized groups often trained at higher peak intensities, so part of the effect may be design. [22]
- ACSM 2026: periodization "did not consistently impact" outcomes; hypertrophy unaffected by linear/undulating/non-periodized; strength effect "could not be determined". [1]
- Rep-range variation is probably useful for hypertrophy; avoid more than ~3 consecutive weeks entirely in low-rep (<6) / high-RIR work for hypertrophy goals. (Practitioner)

Conclusion: the specific model matters less than having progression. Default for non-peaking lifters: double progression inside a volume-ramp mesocycle (below), optionally with DUP rep targets across the week.

## Mesocycle and macrocycle construction

### Mesocycle templates

| Template | Length | Volume | RIR | Deload |
|---|---|---|---|---|
| **Hypertrophy accumulation (default)** | 5 working weeks + 1 deload (allowed 4–8) | Start near the lower end of the target; +1 set/muscle/week | 3 → 2 → 1 | Final week, ~50% sets |
| Intermediate hypertrophy/strength, longer | 6–8 working weeks + 1 deload | +0–2 sets/muscle per 1–2 weeks, plateau, then drop | Start 3, end 1–2 (0–1 only on isolation) | Fatigue-triggered or at end |
| Novice | No mesocycle needed; run LP 3–6+ months until it stalls | Constant | 2–3, avoid failure | Only on symptoms or after repeated resets |
| 5/3/1 cycle | 3 working + 1 deload week (4 weeks) | Fixed; AMRAP drives next TM | AMRAP ≈ 1–2 RIR if done conservatively | Week 4 built in |
| Block (athlete peaking) | 2–6 weeks per block; ~10–16 weeks to a peak | Accumulation high volume → realization low volume/high intensity | Falls | Taper in the last block |

The volume-ramp mesocycle is theory- and practitioner-derived (RP-style), not trial-verified; sources are secondary summaries. [23] (Practitioner)

### Worked 6-week mesocycle (intermediate hypertrophy, one muscle group)

Assumptions: intermediate (weekly default 12 sets, range 10–20 — see [variables](03-variables.md)), 2 sessions/muscle/week, fractional set counting. Weeks 1–5 are working weeks; week 6 is the deload. Average working volume = 12 sets/wk. Peak (14) stays well under the ~18–20 diminishing-returns zone.

| Week | Weekly hard sets (this muscle) | Sets per session (2 sessions) | RIR on moderate/isolation work | RIR on heavy barbell compounds | Load / rep action |
|---|---|---|---|---|---|
| 1 | 10 | 5 + 5 | 3 | 3 | Pick loads that hit the bottom of each range at target RIR |
| 2 | 11 | 6 + 5 | 2–3 | 3 | Add reps within the range |
| 3 | 12 | 6 + 6 | 2 | 3 (≥2) | Add reps; add load where the top of range is hit |
| 4 | 13 | 7 + 6 | 1–2 | 2–3 | As above |
| 5 | 14 | 7 + 7 | 1 (isolation last set 0–1) | 2 | Best performance week; set new rep/load bests |
| 6 (deload) | 6–7 (−50%) | 3 + 3 or 4 | ≥3 | ≥3 | Keep loads same (or −5–10%); no new PRs; keep frequency |

Rules for using the table:
- Next mesocycle: restart at week 1 volume (10 sets) or ~1 set above last meso's week 1 if recovery was good; start loads at the week-5 loads minus one rep-step, not at the deload loads.
- Beginner variant: 8 sets/week default, no ramp needed; use LP instead.
- Advanced/priority muscle: start ~12–13, ramp +1/wk to 16–18, never beyond ~20–22 for >a few weeks (see [variables](03-variables.md)).
- Per-session cap: 10 fractional hard sets per muscle; if the weekly ramp would exceed that per session, add a session instead.
- Hold sets constant if recovery markers worsen (≥2 deload signals below); do not keep adding sets.
- Mixed goals: strength lifts keep their set count (2–3 sets/exercise, 6 sets/wk/lift-specific muscle) and ramp load/RIR instead of volume.

### Macrocycle (months to a year)

1. Stack 2–4 mesocycles; every mesocycle ends in a deload.
2. Vary emphasis across mesocycles (e.g. hypertrophy meso → strength meso with heavier ≥80% loads and 1–6 reps → hypertrophy meso), unless a dated peak requires block structure.
3. Keep core lifts constant within a meso; rotate ~30–50% of accessories at meso boundaries (see rotation).
4. Place an optional lower-volume "maintenance" meso (4–6 sets/muscle/wk, heavy loads) around travel, high life stress or a conditioning-priority block (see [goals](04-goals.md), [hybrid](10-hybrid.md)).
5. Peak (dated meet/test only): accumulation 3–6 wk → intensification 3–4 wk → realization/taper 1–2 wk.

## Deloads

| Parameter | Default | Alternative |
|---|---|---|
| Duration | 1 week (4–7 days) | 3–5 days for minor fatigue |
| Timing | Reactive (symptom checklist) or every 4–8 weeks of hard training; proactive after 6–8 consecutive hard weeks with no symptoms; novices rarely | Fixed every 4–6 weeks in RP-style blocks |
| Volume | Cut sets 30–50% | Up to −50–60% if heavily fatigued |
| Load | Keep (or −5–10%); intensity-only reduction is less favoured | — |
| Proximity to failure | Keep RIR ≥3 | — |
| Session frequency | Keep the same | Reduce sessions if life stress is high |
| Targeted deload | Reduce/remove only exercises that load the sore area | — |

Reactive checklist (Helms/RippedBody): deload when **≥2** of: dreading training, worse sleep, stalled/declining loads on ≥2 lifts, high life stress, new aches. [24]

Evidence:
- Delphi consensus (Bell 2023): deloading = planned reduction of training stress to mitigate fatigue and enhance preparedness; reduced volume is the most common lever; keep it brief. Expert opinion, "under-researched". [25][26] (Practitioner)
- Coleman 2024 RCT (n=39 resistance-trained, 29 M/10 F): **complete cessation** for 1 week at the midpoint of a 9-week high-volume program → no difference in lower-body size, power or endurance; lower-body isometric and dynamic strength **greater in the continuous group**; slight readiness advantage for continuous. It tested full rest, **not** a reduced-volume deload. [5] (Moderate, single RCT; Contested for design)
- No RCT of a reduced-volume deload exists. Reactive vs proactive timing is unresolved.

## Plateau detection and fixes

A plateau is no improvement on a **priority lift** for ~3–4+ weeks versus the **recent 6–8 week best** (not lifetime best), with consistent training, sleep, protein and manageable stress. A single bad week is not a plateau. Also expect: first detectable strength gain averages ~4.3 weeks (range 1–12); judge a mesocycle over ≥4 weeks. [4][27] (Practitioner/Moderate)

Diagnosis order: (1) logging/measurement noise (1RM noise 3–5%); (2) recovery (sleep, food, stress); (3) accumulated fatigue; (4) volume too low or too high; (5) technique/weak link; (6) model mismatch (level too advanced for per-session jumps, or too-fast TM).

| Pattern | Likely cause | Fix |
|---|---|---|
| Stall <3 weeks | Noise | Do nothing structural; check sleep/food/stress |
| Several lifts stall or feel heavy, ≥2 deload signals | Fatigue | Deload 1 week, then consider cutting volume ~⅓ for 2 weeks |
| One lift stalls, others progress | Technique, sticking point, weak link | Add 3–4 sets of 5–8 of a targeted accessory; change rep scheme (e.g. 4×6 → 5×5); shift focus to another lift for 4–6 weeks |
| Progress slowed uniformly with training age | Expected | Compare with expected rates (intermediate ≈ +1 rep/week; advanced ≈ +1–2 reps/month); do not change anything yet |
| Load jumps too large | Equipment | Progress by reps → add a set → add load |
| Intensity-only changes fail, recovery good | Under-stimulus | Add +1–2 sets/muscle/week gradually |
| Novice LP failures repeat | Linear stage ending | Reset ~10%, smaller steps (1.25–2.5 kg), or weekly progression; then move to intermediate model |

Layoffs: ~28 days off costs little strength in younger lifters (a blog-derived threshold; Bosquet 2013 [28] gives only direction, larger losses in >65 y). IF <4 weeks off THEN resume near previous loads. IF >4 weeks THEN restart ~10–20% lighter and ramp over 2–3 weeks. "Regain in about half the layoff time" is a **practitioner estimate** [29], not a measured result.

## Exercise rotation

| Rule | Detail |
|---|---|
| Core lifts | Keep constant for the whole mesocycle (4–8 weeks) so progress is measurable |
| Accessories | Swap ~30–50% at the start of the next mesocycle; same pattern and target muscle; systematic, not random |
| New exercise | Start conservative: RIR 3–4 for the first 1–2 weeks, then progress |
| Adherence/motivation problem | Allow more rotation; no strength/hypertrophy penalty found, motivation higher |
| Painful/stale exercise | Swap immediately with a same-pattern substitute (see [exercise library](12-exercise-library.md)) |

Evidence: Baz-Valle 2019 (21 trained men): random exercise/rep rotation each session equalled fixed on muscle thickness and strength; motivation higher with rotation [30]. Kassiano 2022 systematic review (8 studies, 241 young men): some systematic variation may help regional hypertrophy and dynamic strength; excessive/random variation may compromise gains [31]. (Moderate-weak; small base, mostly young men, 8–12 weeks.)

## What to log

| Log | Why |
|---|---|
| Exercise, load, reps per set, number of sets | Overload check |
| RIR/RPE per set (esp. top or last set) | Effort control; spot underestimation |
| Date; bodyweight (weekly average) | Trend context |
| Session notes: sleep, stress, pain, joint irritation | Deload/plateau triggers |
| Estimated 1RM (Epley: weight × (1 + reps/30)) or "best set at target RIR" | Comparable performance metric |

Review every 3–4 weeks against the recent 6–8 week best. Average ≥3–4 weeks before acting on gains <5%. Do not use a 1RM test as the only success metric. [4]

## RPE ↔ RIR ↔ %1RM reference (general convention)

Labelled **general convention from RPE charts, not tested against a single source**; individuals vary. Each RIR ≈ 2–3 %1RM lower at the same reps. RPE 10 = 0 RIR, 9.5 = 0–1, 9 = 1, 8 = 2, 7 = 3 (Zourdos 2016 scale) [32].

| Reps | RPE 10 (0 RIR) | RPE 9 (1 RIR) | RPE 8 (2 RIR) | RPE 7 (3 RIR) |
|---|---|---|---|---|
| 1 | 100% | ~97% | ~95% | ~92% |
| 3 | ~93–94% | ~91% | ~89% | ~86% |
| 5 | ~87% | ~85% | ~82% | ~80% |
| 8 | ~80% | ~78% | ~75% | ~73% |
| 10 | ~75% | ~73% | ~70% | ~68% |
| 12 | ~70% | ~68% | ~65% | ~63% |

The RPE 10 column is the chart base; other columns are derived at ~2.5%/RIR. Default working-set effort is RPE 8 / 2 RIR; beginners, older adults and heavy barbell compounds RPE 7 / 3 RIR (see [variables](03-variables.md)).

RIR bias: across 13 publications (414 participants) mean RIR under-prediction ≈ 0.95 reps (SD 1.45); error is lower closer to failure and at ≤12 reps; sex and experience had little effect. [33] (Moderate)

## Decision rules

**Model choice**
- IF true beginner (<~6 months consistent lifting, or can add load nearly every session) THEN LP on main lifts (+2.5 kg upper, +5 kg lower per session), full body ~3×/week, 2–3 RIR, no deload or formal periodization.
- IF novice misses reps on the same load for 2–3 consecutive sessions THEN drop ~10%, rebuild in 1.25–2.5 kg steps, or move that lift to weekly progression. (Use the program's own rule if running a named program, e.g. Starting Strength: second consecutive failure → 5% + light day.)
- IF hypertrophy goal and not a novice THEN double progression with rep range + RIR (e.g. 3×8–12 @ 2 RIR) inside the 5+1 mesocycle.
- IF intermediate strength goal THEN (a) 5/3/1-style wave with TM +2.5 kg upper / +5 kg lower per cycle, or (b) top set @ RPE 8 + 1–3 back-offs at −5–10%.
- IF the user prefers feel-based training or has variable readiness THEN prescribe RIR/RPE ranges (equivalent strength results); calibrate by taking a final set of a safe lift near failure and adding ~1 rep to the perceived reps left.
- IF advanced THEN progress per block (≈ +1–2.5% load/block or +1–2 reps/month), use autoregulated top sets.
- IF the user wants a named program THEN state its exact version, increments and reset rule; do not mix rules (e.g. 5/3/1 percentages with StrongLifts increments).

**Periodization**
- IF no dated peak THEN simple undulation or double progression; model choice is low-stakes.
- IF training the same lift ≥2×/week for strength THEN assign different rep/intensity per session (DUP: heavy 3–5 @ RPE 8, medium 6–8, light 10–12). (Practitioner extrapolation)
- IF dated meet/test THEN block or linear structure (accumulation → intensification → realization/taper 1–2 wk).
- IF the user asks for conjugate THEN state no controlled evidence exists; offer for advanced lifters only.

**Mesocycle and deload**
- IF building a hypertrophy block THEN use the 6-week table: start at the low end of the weekly target, +1 set/muscle/week, RIR 3 → 1, then deload.
- IF ≥2 of (dreading sessions, worse sleep, flat/declining performance on ≥2 lifts, higher life stress, new aches) THEN deload now: −30–50% sets, same load, RIR ≥3.
- IF no symptoms but 6–8 consecutive hard weeks have passed THEN schedule a proactive deload.
- IF novice progressing every session THEN skip deloads.
- IF soreness/pain is local to one joint/muscle THEN targeted deload (remove or reduce those exercises only). Persistent pain → refer to a clinician; out of scope here.

**Plateau and rotation**
- IF a lift stalls <3 weeks THEN no structural change.
- IF priority lift flat 3–4+ weeks AND other lifts also stall THEN suspect fatigue: deload 1 week, then consider −⅓ volume for 2 weeks.
- IF only one lift stalls THEN technique/weak-link fix (targeted accessory, rep-scheme change, rotate focus for 4–6 weeks).
- IF accessories become stale, painful or boring THEN swap ~30–50% at the next mesocycle start, same pattern and muscle.

## Common mistakes

- Giving advanced complexity (block, conjugate, nSuns 6-day) to novices, or leaving advanced lifters on per-session jumps.
- Adding load faster than reps allow (5/3/1 TM jumps too fast; applying ACSM's 2–10% rule to small muscles).
- Fixed increments regardless of lift size (5 lb is 3.7% vs 1.2% of a 135 vs 405 lb squat).
- Training to failure on every set with no RIR target, then wondering why fatigue accumulates.
- Trusting RIR blindly: underestimating reps left by ~1, more so on early/long sets.
- Calling one bad week a plateau.
- Deloading too often (novices) or never (advanced); treating a deload as total rest when practitioners prescribe reduced volume at maintained load.
- Random exercise changes every session, so no progression is measurable.
- Adding volume to break every plateau without checking recovery.
- No defined progression, reset or deload in the written plan.
- Running 5/3/1 off 100% of 1RM instead of a ~90% TM.
- AMRAP sets taken to true failure every session.
- Staying entirely in low-rep, high-RIR ranges for hypertrophy for >3 weeks.
- Mixing program rules or citing a program without a version (Texas Method %, PPL increments and nSuns sets differ by source).

## Evidence notes

| Claim | Grade | Note |
|---|---|---|
| Periodized > non-periodized for 1RM | Moderate | Moesgaard ES 0.31 (0.04–0.57); Williams 0.43, disputed; design confounds [2][22] |
| No periodization effect on hypertrophy; LP ≈ undulating | Moderate | ES 0.13 and 0.05, both n.s. [2]; ACSM 2026 agrees [1] |
| Undulating > linear for 1RM | Contested | Only in trained lifters; CI touches zero [2] |
| Block vs undulating/traditional | Contested | Conflicting trials [21] |
| Conjugate | Practitioner | No controlled trials |
| Autoregulation ≈ percentage-based for 1RM | Moderate | Few studies; velocity data may not transfer to RPE [8][9] |
| Load vs rep progression equal for hypertrophy | Moderate | Single RCT [7] |
| Mesocycle +1 set/week ramp, RIR 3 → 1 | Practitioner | Secondary summary of RP; not trial-verified [23] |
| Deload parameters | Practitioner | Delphi consensus; one RCT tested full rest only [5][25] |
| Exercise rotation | Moderate-weak | Small base [30][31] |
| Plateau definition (3–4 weeks vs 6–8 week best) | Practitioner | [4] |
| RPE/%1RM table | Practitioner | General convention |
| Layoff "half the time" | Practitioner | Blog estimate [29] |

Unverified items: Greyskull original increments, PHUL original, Texas Method 90% figure, nSuns set tables, Williams' bias-adjusted d≈0.23. ACSM 2009 day-count staging (2–3 / 3–4 / 4–5 days) rested on thin evidence; treat as legacy. Experience-specific RIR values have no source. Reference-program numbers come mostly from wiki companions, aggregators and archived copies, not original authors.
