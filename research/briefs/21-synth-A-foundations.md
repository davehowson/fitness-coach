## Page scope
- `01-principles.md`: what makes a good workout/program, top-down. Fit-between-plan-and-person framing; each training principle (specificity, overload, SRA, individualization, managed variation, fatigue management, reversibility, minimum effective dose, adherence) with how it shows up in a plan; the health floor; the top-down design process.
- `02-intake.md`: exact intake checklist for the LLM (required vs optional fields, sensible defaults when a field is missing, red flags that require referral or clearance, how each answer changes the plan). Include a copy-pasteable intake question list and a structured intake schema (YAML-like).
- `14-quality-checklist.md`: a scored checklist the LLM runs on any generated plan before returning it: goal alignment, weekly sets per muscle in range, frequency, per-session cap, pattern balance, recovery spacing, progression rule, deload, time fit, equipment fit, substitutions, safety. Each item gives a pass condition with numbers from the canonical defaults and a fix if it fails.
