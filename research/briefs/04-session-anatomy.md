# Brief 04: Session Anatomy: Building a Single Workout

**Output file:** `research/raw/04-session-anatomy.md`
**Output format:** follow `research/briefs/00-output-contract.md` exactly. Read it first.
**Context:** `research/01-domain-map.md` shows how this topic fits the whole wiki. Read it.

## Scope — research all of the following
- Warm-up: evidence on general warm-up, dynamic stretching vs. static stretching, RAMP protocol, specific warm-up / ramp-up sets. Durations.
- Ordering blocks: power/plyo → main strength lift → secondary compound → accessories → isolation → core → conditioning. Evidence and rationale.
- How many exercises per session, sets per session, and per-muscle per-session volume caps (diminishing returns per session).
- Session duration: time budgeting for 30, 45, 60, 75, 90 minute sessions; what to cut first when short on time.
- Pairing strategies: supersets (antagonist, agonist, non-competing), tri-sets, circuits, giant sets — when to use and time savings.
- Movement pattern balance within a session and across the week (push:pull ratio, knee- vs hip-dominant, unilateral work, core/anti-rotation, carries).
- Cool-down: evidence (or lack) for cool-downs and stretching after training.
- Provide 3–5 concrete example session templates (e.g. 45-min full body, 60-min upper, 75-min lower) with exercise categories, sets, reps, rest.
