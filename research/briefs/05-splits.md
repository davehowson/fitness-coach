# Brief 05: Training Splits Catalog

**Output file:** `research/raw/05-splits.md`
**Output format:** follow `research/briefs/00-output-contract.md` exactly. Read it first.
**Context:** `research/01-domain-map.md` shows how this topic fits the whole wiki. Read it.

## Scope — research all of the following
- Catalog every common split: full body, upper/lower, push/pull/legs (PPL), PPL x2, body-part ("bro") split, Arnold split (chest/back, shoulders/arms, legs), torso/limbs, anterior/posterior, push/pull, PHUL, PHAT, upper/lower/full hybrids (ULPPL), specialization splits, powerlifting-style squat/bench/deadlift-day splits.
- For each split: day layout, which muscles per day, resulting per-muscle frequency, typical sessions/week, volume per session, pros, cons, best-fit person (experience, goal, schedule), and common variants.
- Evidence comparing splits (e.g. full body vs. split routine RCTs and meta-analyses).
- How splits handle missed days and schedule irregularity (rolling vs. fixed-calendar splits).
- Rest-day placement patterns per split.
- Include a comparison table of all splits.

## Done when
- `research/raw/05-splits.md` exists with every section from the output contract.
- Every scope bullet above is addressed (or explicitly marked as not findable, with why).
- 12+ distinct sources with URLs; key findings carry evidence grades.
