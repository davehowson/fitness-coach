## Scope — research all of the following
- Catalog well-known, proven programs as worked examples: e.g. Starting Strength, StrongLifts 5x5, GZCLP, Greyskull LP, 5/3/1 (and variants: BBB, for Beginners), Texas Method, Madcow 5x5, nSuns, Reddit PPL (Metallicadpa), PHUL, PHAT, Candito, Sheiko (brief), Renaissance Periodization hypertrophy approach, Jeff Nippard / evidence-based hypertrophy programs, Couch to 5K, Hal Higdon-style running plans, Hybrid athlete templates, Convict Conditioning / r/bodyweightfitness Recommended Routine.
- For each: goal, target level, days/week, split, structure (exercises, sets, reps, %), progression scheme, deload/reset rules, strengths, criticisms.
- Accuracy matters: verify details from the original or authoritative sources; note where versions differ.
- Map programs into a table by (goal × level × days/week) so an LLM can pick an archetype.
- Extract recurring design patterns that appear across successful programs.
